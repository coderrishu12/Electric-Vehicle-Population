# Electric Vehicle Dashboard (Power BI)

This project showcases an interactive Power BI dashboard built using the Electric Vehicle Population Dataset. The dashboard provides insights into the adoption, distribution, and growth of electric vehicles (EVs), including both Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).

## 📊 Features

* Total Registered Vehicles – Overall count of EVs in the dataset.
* Vehicle Type Breakdown – Distribution of BEVs and PHEVs.
* Geographical Analysis – EV registrations by location for regional insights.
* Manufacturer & Model Trends – Popular automakers and top EV models.
* EV Technology Insights – Battery range, model year trends, and performance indicators.

## 🛠️ Tools & Technologies

* Power BI for data visualization and dashboard creation
* CSV Dataset as the primary data source
* Data Cleaning & Transformation using Power Query

## 🚀 Problem Statement

With the rapid adoption of electric vehicles worldwide, it is essential to analyze their growth, distribution, and trends for policymaking, infrastructure planning, and business strategy. This dashboard addresses the problem by providing an easy-to-understand, visual representation of EV adoption trends, enabling stakeholders to make informed decisions.

## 📂 Files in Repository

* `Electric_Vehicle_Population_Data.csv` – Raw dataset used for analysis
* `PowerBiDashboard.pbit` – Power BI dashboard template file
